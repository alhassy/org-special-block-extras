#+title: Tests

Everything is ERT underneath, written with [[https://github.com/alhassy/snap][snap]]:
- =org-*-tests.el= :: one file per module or topic; e.g., =org-box-block-tests.el= ↔ =org-box-block.el=.
  - =deftest "sentence" …= :: a plain test, named by its sentence.
  - =org-deftest "sentence" :text "…" :at "…" …= :: a test in a fresh Org buffer holding =:text=, with point just after
    =:at=; =:mode= picks another mode, such as =org-graph-edit-mode=. For many such buffers in one test, say in a
    loop, =with-org-test-buffer= takes the same keys.
  - =define-org-block-parse-test= :: Org text ↦ how its first block parses: =:name=, =:main-arg=, =:kwdargs=, =:contents=.
  - =define-org-call-test= :: a handler call ↦ its exact output; e.g., =:call (org-block/box 'html "hi" nil)=.
  - =define-org-export-test= :: an Org string ↦ its export; e.g., =:input "#+begin_shout …" :to latex=.
  - Shared machinery ---=deftest=, =org-deftest=, =using=, =exporting=, and the relations--- lives in =org-test-utils.el=;
    a test's temporary =org-defblock= may not reuse a built-in block's name, since its cleanup would undefine it.
- =graph/org-graph-*-tests.el= :: the =graph= block, sharing =graph/org-graph-test-utils.el= and its =define-graph-test=.
- =:demo= blocks :: the manual's showcase examples are its =:demo= blocks: each holds its source and, in a
  =#+RESULTS:= drawer, a snapshot of its HTML & LaTeX; =org-demo-tests.el= checks every one still renders so, as do
  those of =demos.org=, which are tests rather than docs. See the manual's “Demos”.

Relations compare modulo trailing whitespace per line, since editors strip it from expectations on save.

Press =C-c C-c= on any block below.

* Run all tests

In this Emacs session:
#+begin_src emacs-lisp :results none
(dolist (f (append (directory-files "~/org-special-block-extras/tests" t "-tests\\.el\\'")
                   (directory-files "~/org-special-block-extras/tests/graph" t "-tests\\.el\\'")))
  (load-file f))
(ert t)
#+end_src

Exactly as CI does it ---see =.github/workflows/main.yml=:
#+begin_src shell :dir .. :results output
emacs --batch --eval "(package-initialize)" -L ~/lf -L . -L ~/snap -L ~/fancy-C-x-C-e \
  $(for f in tests/*-tests.el tests/graph/*-tests.el; do echo "-l $f"; done) \
  -f ert-run-tests-batch-and-exit 2>&1 | grep -E "^Ran|FAILED"
#+end_src

* Coverage

Each source file's percentage of lines the tests run, as CI reports it; needs =M-x package-install undercover=:
#+begin_src shell :dir .. :results output
UNDERCOVER_FORCE=true emacs --batch --eval "(package-initialize)" -L ~/lf -L . -L ~/snap -L ~/fancy-C-x-C-e \
  --eval "(progn (require 'undercover) (undercover \"*.el\" (:report-format 'text) (:send-report nil)))" \
  $(for f in tests/*-tests.el tests/graph/*-tests.el; do echo "-l $f"; done) \
  -f ert-run-tests-batch-and-exit 2>&1 | sed -n '/Code coverage text report/,$p'
#+end_src

* Notes

- Tests =load-file= via =~/org-special-block-extras/…=, so the repo must live there; CI symlinks it.
- =(package-initialize)= must come /before/ =-L .=; otherwise your installed MELPA copy of
  =org-special-block-extras= shadows the working tree, and we silently test the wrong code.
- Snapshots compare modulo whitespace and case (=org-demo--normalise=), and pin =gensym=, Org's ids, and htmlize's
  colours (=org-demo--export=), so they agree across machines.
- =org-element= warnings about non-Org buffers are benign.
